# zsir-cut 产品设计

状态：草案 v1 · 2026-10-29
依据：[调研文档](https://claude.ai/artifact/PJytj2A1kDu8Wb4aPSkNdR)、[界面设计稿](https://claude.ai/artifact/6g8fzZAHD7GhqE4EeUyF9d)（草稿 3）、Bill 在设计稿上的逐条意见。
相关决策：ADR-0013（产品通用）、ADR-0014（对话面板与「决定」）、ADR-0015（直接导出的范围）。

本文写「做什么、给谁、长什么样、先做哪些」。数据和命令的合同在 `docs/spec/`，视觉规范在 `docs/design.md`（第 3 步写）。两者和本文冲突时，先改本文，再改它们。

## 1. 定位

给剪辑师和 Agent 共用的时间线剪辑工具。Agent 在这里做粗剪、字幕和结构整理，人在这里看、做决定、微调，然后交给 Final Cut Pro、DaVinci Resolve、Premiere Pro 收尾，或者直接导出文件。

- **通用。** 它是剪辑工具，不是采访专用工具。界面文案、轨道名、默认选项都不写死任何题材。采访口播只是第一批拿来验收的素材，见 ADR-0013。
- **不做第四个 NLE。** 调色、混音、包装、特效交给 NLE。我们管剪辑决策、字幕和交接。
- **Agent 优先。** 剪辑动作由用户自己的 Agent（Claude Code、Codex 等）完成。软件负责把结果摆清楚，让人能看、能判断、能接手。

## 2. 产品原则

1. **工程数据为准。** 剪辑、字幕、章节、待决事项都写进工程文件。聊天记录只是过程，换一个 Agent、换一台电脑，打开工程就能接着做。
2. **界面是 Agent 接口的一个客户端。** 界面上的每个操作都对应一个 MCP 工具（CLI 有同名命令）。界面上没有的操作，Agent 也要能做。新功能的顺序是：先定动词，再画按钮。详见第 6 节。
3. **人做决定，AI 做执行。** AI 遇到拿不准的地方不擅自定，而是生成「决定」请人选，见第 4 节。人批准过的内容，AI 不能自动改。
4. **不动素材。** 任何操作都不删除、移动或改写素材文件。
5. **交接可信。** 交给 NLE 之前，先告诉用户哪些原样带过去、哪些近似、哪些带不过去。

## 3. 桌面版布局

一个窗口，六个区域。从上到下、从左到右依次是：

| 区域 | 作用 |
|---|---|
| 菜单栏 | 工程名、版本、AI 草稿状态，右侧是「导出」 |
| 功能区（左） | 四个标签：**AI**、**素材**、**章节**、**字幕**。用来发起操作、设置参数 |
| 预览（中） | 播放时间线或素材，显示字幕 |
| 参数区（右） | 显示左侧当前功能的结果和属性 |
| 工具栏 | 选择、切割、加标记、撤销、重做、吸附、缩放 |
| 时间线 | 视频、声音、字幕三类轨道 |

**一个功能面板对应一套参数面板。** 左边选哪个标签，右边就换成与它配套的内容：

| 左：功能区 | 右：参数区 |
|---|---|
| AI：和本机 Agent 对话 | 决定：AI 留下的待决事项 |
| 素材：素材网格或列表，`I` / `O` 设范围，`Q` 或拖动加到时间线，`⌘ +` / `⌘ −` 缩放 | 素材信息：封面、主色、名称、注释、链接、标签、文件夹、评分、规格、在时间线里用了几段 |
| 章节：选视图、设层级、让 AI 重新分章、复制 Markdown | 章节大纲：一级、二级标题加时间码，点标题跳到对应位置 |
| 字幕：识别设置（语言、参考文本、AI 找到的专有名词、去除水词） | 两个标签。「字幕」：搜索、查找替换、逐条编辑；「样式」：字体、底色、位置、大小，应用到所有字幕 |

点「导出」时弹出导出面板，见第 5 节。

### 3.1 轨道

轨道只有三类：视频、声音、字幕。每类可以有多条，按「视频 A、视频 B……」「声音 A、声音 B……」「字幕 A、字幕 B……」自动命名，用户可以改名。视频轨上层盖下层。轨道名不带题材含义，空轨道不显示提示语。

## 4. AI 面板与「决定」

AI 面板是一个对话窗口，背后跑的是用户本机安装的 Agent 命令行，例如 Claude Code 或 Codex。用户在输入框里切换用哪一个。软件不带自己的模型，也不保存一套私有的聊天上下文，见 ADR-0014。

- 回复会被渲染成可读的界面：步骤可以折叠，正文有列表和格式，进行中的回复逐字出现，可以随时停止。
- 输入框可以用 `@` 引用素材、标记、字幕条。
- AI 交出一版草稿时，对话里出现草稿卡片，可以直接批准。

**决定**是 AI 剪完后留给人拍板的事，例如「这几处跳剪怎么处理」「成片比目标短 5 秒，要不要补」。

1. AI 在编辑会话里写入决定：问题、选项（推荐的排第一，每项附一句说明）、关联的时间点或对象。
2. 参数区列出全部决定，一次展开一张，显示进度（已定、待定、排队中）。
3. 用户点选项，或在「其他想法」里写一句，按回车发出。软件把选择写回工程，同时在对话里自动发一条消息，AI 接着执行。
4. 用户也可以跳过；没答的决定不阻止批准，但批准前会提示还有几件没定。

决定挂在编辑会话上，存进工程。Agent 用 MCP 读取和回答决定，和界面上点选效果相同。

## 5. 导出

导出面板是一张节点图：左边是成片预览（鼠标在画面上左右移动就能快速预览），向右分出几个去处。每个去处是一整张可点的卡片，点哪个导出哪个。卡片上用文件图标画出会得到什么，并写一句注意事项。

| 去处 | 得到的文件 | 一期 |
|---|---|---|
| Final Cut Pro | FCPXML（含字幕） | 有。用户在 FCP 里手动导入 |
| DaVinci Resolve | OTIO 时间线 + SRT | 有。字幕要单独导入 |
| Premiere Pro | XML 时间线 + SRT | 有。字幕要单独导入 |
| 直接导出 | 可多选：SRT、音频 WAV、成片 MP4 | 一期只有 SRT 和音频；成片 MP4（可选烧进字幕）放二期，见 ADR-0015 |

去 NLE 的三个去处，导出前都会试算损失报告，有带不过去的内容时在卡片上标出来。

## 6. Agent 能控制一切

软件里所有操作，包括界面上没有的，都通过 MCP 暴露给 Agent。CLI 和 MCP 调用同一个内核函数，返回同样的结果（已有测试保证）。界面也调用同一批动词，不另写逻辑。

验收标准：界面上每个会改变工程或产生文件的按钮，都能指出它调用的是哪个动词；没有动词的按钮不合入。

表里「还要补的」第 3 步各项，规格已写好（2026-10-29），实现任务见 `docs/tasks/step-3.md`。

| 操作类别 | 现在已有的动词 | 还要补的 | 什么时候 |
|---|---|---|---|
| 导入素材 | `import_media`（含找回离线素材） | 素材的标签、文件夹、评分、注释、链接的读写 | 第 3 步 |
| 时间线与剪辑 | `edit`（放置、删除区间、修剪、移动、合拢、轨道、标记、转场）、`undo` / `redo` | 新建轨道按类型自动命名 | 第 3 步 |
| 字幕 | `transcribe`、`edit` 字幕域（改字、隐藏、断句、样式、字幕轨） | 参考文本里抽专有名词作热词；识别时自动去水词；批量查找替换 | 第 3 步 |
| 章节 | `edit` 的标记操作（`chapter` 类标记） | 章节层级；让 AI 按字幕和剪辑生成章节 | 第 3 步 |
| 审批与决定 | `session_begin` / `session_review` / `session_approve` / `session_reject` | 写入、列出、回答决定 | 第 3 步 |
| 读取与自查 | `inspect`、`read_transcript`、`diff`、`validate`、`view_timeline`、`job_status` | — | 已有 |
| 导出 | `export`、`render_preview`、`record_handoff_check` | 单独导出音频；成片导出（二期）；多机位选项（二期） | 见路线图 |
| 界面状态 | 无 | 打开某个面板、跳到某个时间、选中对象、播放。由桌面版提供，让 Agent 能把东西指给用户看 | 第 3 步 |
| 多机位 | 无 | 建多机位片段、切换角度、展开成普通片段 | 二期 |

### 二期

按场景排列，顺序可以调整。

**1. 多机位剪辑**

- 场景：用户给一个素材文件夹，对 AI 说「剪成多机位」。
- 流程：导入全部素材 → 按声音（有时码时按时码）对齐 → 合成一个多机位片段，放在**一条视频轨**上 → AI 或用户在需要的位置切换角度。时间线上看到的是一条轨，片段上标出每段用的哪个角度，可以随时换。
- 导出：每个去 NLE 的去处多一个选项「导出多机位」。
  - 勾选：导出成该软件的多机位片段。例如 FCP 导入后就是多机位片段，能在角度检视器里继续切换。
  - 不勾：展开成普通片段，一条视频轨按角度切好，和现在的导出一样。
  - 某个软件的交换格式表达不了多机位时，只能展开，并写进损失报告。FCP 的 FCPXML 支持多机位；Premiere 和 Resolve 要先实测。
- 要做的：调研三家的多机位交换写法；新 ADR；schema 增加多机位实体（角度、对齐偏移、声音取哪个角度）；新动词；三家导出各加一种写法；测试工程增加多机位素材。
- 验收：FCP 导入后是可切换角度的多机位片段；展开模式下逐切点零帧偏差；切换角度后字幕仍跟着说话的人走。

**2. 直接导出成片**

成片 MP4，可选烧进字幕，字幕按「样式」里的设置渲染。要先写渲染规格：码率档位、字体打包、烧字幕用的渲染器和许可证。

**3. 章节的更多视图**

- 思维导图：全片结构一张图。
- 详细大纲：每级标题下一句概述，加缩略图。
- 时间地图：横向时间线上的章节小地图。

结果都显示在参数区；切换视图、调参数在功能区。

**4. 其他**

- 从 NLE 导回、往返（调研里已定放二期）。
- 字幕识别的更多选项。
- 剪映草稿导出。

## 8. 不做

- 自研编解码和调色。
- 「选题到成片」的生成式流水线。
- MG 包装、动态标题、复杂特效。
- 用浏览器自动化或 CEP 文件轮询控制 NLE。
- 软件自带模型或私有聊天上下文。
