# ADR-0001 首发形态：Skill + CLI 先行

状态：已采纳 · 2026-10-21

## 背景

产品的核心是 Agent 剪辑加人工审批。最大的不确定性在数据模型和命令协议是否好用，而不是界面。先做界面，协议问题会在界面写完后才暴露，返工代价高。设计系统本身也要依赖数据模型。

## 决策

第一个可用版本是 Claude Code Skill 加 `zcut` 命令行，背后是无头内核。桌面界面放到第 3 步，内核在真实采访项目上跑通之后再做。时间线 JSON 和命令协议从第一天就按最终形态设计。

## 后果

- 剪辑师在一期没有图形界面，审批靠 CLI、参考预览和交接到 NLE 后检查。
- 第 3 步的界面必须调用同一个内核，不能另起一套逻辑。
- 协议问题在第 2 步真项目里暴露，修起来便宜。

## 考虑过的其他方案

- 先做桌面编辑器再接 Agent：界面工作量大，且会把未验证的数据模型固化进界面。
- 只做宿主插件，例如 Premiere UXP 面板：被单一宿主绑定，FCP 用户最多却没有插件 API。
