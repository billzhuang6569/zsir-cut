# ADR-0013 产品通用，首批验收用采访

状态：已采纳 · 2026-10-29 · 取代 ADR-0008

## 背景

ADR-0008 把首批场景定为采访口播，原意是选验收素材和功能范围。到第 3 步画界面时，这个限定渗进了界面：轨道叫「空镜」，提示语写「拖入空镜素材，盖在跳剪上」，Skill 的描述也只说采访、口播。Bill 在设计稿上指出，这是通用的剪辑工具，不是只针对采访的。调研文档的定位也是剪辑师和 Agent 共用的「时间线中间站」，采访只是验收示例。

## 决策

- 产品和界面保持通用：界面文案、轨道名、默认选项、Skill 的触发描述都不写死任何题材。
- 首批**验收素材**仍然是采访口播，第 2 步的验收情景和测试工程不变。
- 第 3 步实现完成后，至少用一个非采访素材的项目走一遍，检查通用性。
- MG 包装、动态标题仍然不做；多机位放到二期，见 `docs/product.md` 第 7 节。

## 后果

- 轨道按「视频 A / B、声音 A / B、字幕 A / B」自动命名，不出现题材相关的名字。
- 「去口头语」「按词表改字」这类能力在界面上叫通用的名字（去除水词、参考文本），不叫采访专用的名字。
- Skill 的描述放宽，不再只写采访和口播。

## 考虑过的其他方案

- 维持 ADR-0008：一期做成采访工具，二期再通用。界面一旦按采访设计，二期要改文案、改默认值、改轨道模型，返工更大。

依据：2026-10-29 Bill 在界面设计稿上的意见，以及他对产品设计对照页的回复。
