# ADR-0008 首批场景：采访口播

状态：已被 ADR-0013 取代 · 2026-10-26

## 背景

调研列了采访口播、品牌混剪、活动快剪、MG 包装几类场景，需要选首批来定验收素材和功能范围。

## 决策

首批只做采访口播。暂不做 MG 包装和动态标题。验收情景：把一组采访整理成三分钟，优先讲核心观点，去掉重复表达，保留必要停顿，按客户词表校正字幕，导出 FCP 接手版。

## 后果

- 测试工程和评测集以采访素材为主：单机位、双机位、中英混说、品牌词和数字。
- 「按 token 范围删内容」是最重要的编辑操作，字幕跟随剪辑是最重要的保证。
- 片头包装、动态标题、多机位片段一期不做。

## 考虑过的其他方案

- 品牌混剪：更依赖画面判断和包装，Agent 能力和验收都更难。

依据：2026-10-26 Bill 的回答。
