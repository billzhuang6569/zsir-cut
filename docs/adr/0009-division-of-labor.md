# ADR-0009 分工：Claude 统筹验收，Codex 实现

状态：已采纳 · 2026-10-26

## 背景

两个 Agent 同时改代码容易互相覆盖，责任也不清楚。验收需要独立于实现的人来做。

## 决策

- Bill：产品决策，批准 spec 和里程碑，实机验收。
- Claude：写 spec、拆任务、经 Codex 插件派发代码任务、审 PR、跑验收，把失败写成新的 fixture。不写功能代码，不改 Codex 的代码。
- Codex：按 spec 实现，一个任务一个 PR，不合并自己的 PR。
- spec 类 PR 由 Bill 批准后合并；代码类 PR 在 CI 和验收通过后由 Claude 合并。

## 后果

- spec 必须足够精确，Codex 才能不靠猜。实现中发现的 spec 问题写进 PR，由 Claude 改 spec。
- 验收依赖测试工程，所以第 0.6、0.8 步要在功能代码之前完成。

## 考虑过的其他方案

- Claude 同时写代码：省一次交接，但实现和验收是同一方，容易放过自己的问题。

依据：分步讨论的最后一轮；2026-10-26 Bill 确认用 Codex 插件执行代码。
