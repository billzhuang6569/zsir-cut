# ADR-0015 直接导出：一期只做 SRT 和音频，成片放二期

状态：已采纳 · 2026-10-29

## 背景

Bill 在导出面板里加了「直接导出」：不进剪辑软件，直接出视频、SRT、音频，可以多选。现有规格只交接给 NLE：参考预览是代理视频，画面上不烧录文字，明确「不是成片」；Skill 写「不做成片渲染」。成片要正式码率，还要按字幕样式烧录文字，需要带文字渲染能力的 ffmpeg 和字体处理，工作量和许可证都要单独评估。

## 决策

- 一期的「直接导出」只有两样：SRT 字幕（沿用交接包里的生成规则），和整条时间线的音频 WAV。
- 成片 MP4（可选烧进字幕）放到二期，先写渲染规格再做。界面上先画出来，置灰并标「下个版本」。

## 后果

- 第 3 步的规格修订要加音频导出：混音规则、采样率、声道。
- 参考预览仍然只给接手人核对用，不当成片。
- 二期写渲染规格时要定：码率档位、字体打包、烧字幕用的渲染器及其许可证。

## 考虑过的其他方案

- 一期全做，包括烧字幕的 MP4：第 3 步会明显变长，而成片不是一期的核心价值。
- 全部放二期：SRT 和音频几乎是现成的，没理由等。
