# ADR-0010 有理数时间与时间映射

状态：已采纳 · 2026-10-26

## 背景

多个开源项目把浮点时间漂移列为真实缺陷来源，例如把 29.97 当成 2997/100，每小时差约 3.6 ms。FCP 里一个片段可以分段变速，也可以有速度坡度、倒放和定格；只用一个恒定速度表示不了。

## 决策

- 所有时间用最简分数的有理数秒字符串，写法与 FCPXML 相同，例如 `1001/200s`。
- 片段的变速用可选的时间映射表示：一组关键点，每点写片段内时刻、源时间和插值方式（线性、平滑、定格）。恒速、分段变速、倒放、定格都是它的特例。
- 一期精确支持线性和定格；平滑坡度原样保存，计算时按线性近似并给出警告。

## 后果

- 内核必须用 `bigint` 有理数运算。
- OTIO 和 xmeml 不支持分段变速时，导出器按段拆片段，并写进损失报告。
- 字幕投影要逐段反算；落在倒放段和定格段的字幕不投影。

## 考虑过的其他方案

- 整数 tick（例如 254016000000 tick/s）直接写进文件：运算方便，但人和 Agent 难读。内部可以用，文件里不用。
- 单一恒定速度：2026-10-26 讨论时确认不够，FCP 的分段变速导回时会丢信息。
