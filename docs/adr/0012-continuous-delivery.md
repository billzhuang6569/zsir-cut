# ADR-0012 连续推进：Claude 自行验收合并，Bill 只在效果和设计上介入

状态：已采纳 · 2026-10-26 · 部分取代 ADR-0009 的合并规则

## 背景

第 0 步里每个 PR 都等 Bill 批准再合并，流程性审批占用了他的时间，而这些 PR 的取舍大多是技术性的。

## 决策

- spec 类和代码类 PR 都由 Claude 验收后自行合并，验收记录留在 PR 评论里。
- Claude 遇到技术取舍时自己决定，并写进 ADR 或 PR 描述，不停下来等批准。
- 只在三种情况请 Bill 介入：验收剪辑效果，包括在 FCP、Resolve、Premiere 里实机导入看效果；验收 Skill 的剪辑效果；产品界面设计。
- 需要 Bill 提供的素材、凭据等阻塞项，先做不依赖它的任务，到时集中提醒。
- Claude 维护一个开发过程可视化网页，用不太术语的话说明进度，每完成一个阶段并验收后更新。

## 后果

- 规格错误的代价由 Claude 的验收兜住，所以每个 Codex 任务仍保留两层验收：重跑 Codex 的检查，加上不复用 Codex 代码的独立脚本复查。
- ADR-0009 里「spec 类 PR 由 Bill 批准后合并」一条不再适用，其余分工不变。

## 考虑过的其他方案

- 维持逐个审批：更稳，但 Bill 的时间应该花在只有人能判断的地方。
