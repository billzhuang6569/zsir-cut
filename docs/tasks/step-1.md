# 第 1 步任务拆分：无头内核与导出

状态：草案 · 2026-10-26 · 上位文档：`docs/plan.md` 第 1 步

## 目标

做出一个能被 CLI 和 MCP 调用的无头内核：读写和校验工程、按命令剪辑和改字幕、撤销、导出三家 NLE 的交接包，以及把采访素材转写成字幕母稿。第 1 步结束时，标准测试工程能导入 FCP，并通过逐切点零帧检查。

## 第 0 步之后核实到的情况

| 项 | 情况 | 影响 |
|---|---|---|
| 本机宿主 | Final Cut Pro 12.4、DaVinci Resolve 21.1.0、Premiere Pro 25.5.0 都已安装 | 实机导入在这台 Mac 上做 |
| FCPXML DTD | FCP 应用包里有 1.0 到 1.14 全部 DTD | 本地能做 DTD 校验 |
| DTD 版权 | DTD 是 Apple 的文件，不能放进公开仓库 | CI 不做 DTD 校验，只做读回比对；DTD 校验是本地验收步骤 |
| ffmpeg 文字渲染 | 本机 ffmpeg 没有 drawtext 和 libass | 参考预览不能烧录字幕和时码，见规格补丁 S1 |
| 重链接 | 命令协议的 18 个动词里没有重链接入口 | 见规格补丁 S1 |

## 顺序

```text
S1 ─┬─ 1.1 → 1.2 → 1.4 → 1.5 → 1.6 → 1.7 → 1.8
    │    └─ 1.3 ──────────┘      │      │
    │                       1.9 ─┘      │
    └─ 1.10 → 1.11 → 1.12             S2
                   └─ 1.13
S3 → 1.11    S5 → 1.12、1.13
S4 → 1.14（worker 部分与内核并行，动词接入等 1.5、1.7）
1.10 → 1.15
```

Codex 一次只在这个工作区里跑一个任务，所以实现任务基本串行。唯一适合并行的是 1.14 的 worker 部分：它只在 `workers/asr/` 里，不碰内核。并行时用单独的 git worktree 给它。

## 每个任务的通用验收

除专项验收外，每个任务都要满足：

1. 受保护路径没有被改，规格类文件只由 Claude 改。
2. 删除 `node_modules` 后用锁定文件重装，lint、typecheck、test、validate:examples 全部通过。
3. GitHub CI 通过。
4. Claude 用不复用 Codex 代码的独立脚本，抽查专项验收里的关键结论。
5. 涉及时间或格式的缺陷，修复时附带回归用例。
