## R1.6 借鉴评估报告要写什么

对时间线交互（拖动、修剪、吸附、缩放、播放头、框选）、预览播放、波形、素材缩略图扫视这四块，逐个回答：

1. 参考仓库里对应代码在哪些文件，大概多少行，依赖什么第三方库（列许可证）。
2. 和我们现有实现比，它解决了哪些我们还没解决的问题。
3. 能不能移植：直接拷贝、改写后移植、只借鉴思路，三选一，并说明理由。它的数据结构和我们的工程文件不一样，写清楚接到我们的 core 和界面动词上要改什么。时间必须仍按有理数处理，不能引入浮点时间。
4. 工作量估计（几个 PR）。

最后给一个推荐顺序。
