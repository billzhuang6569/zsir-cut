# zsir-cut 设计规范

状态：草案 v1 · 2026-10-29
依据：`docs/product.md`、[界面设计稿](https://claude.ai/artifact/6g8fzZAHD7GhqE4EeUyF9d)（草稿 3）、Bill 的设计哲学。

本文写界面「长什么样、怎么动」。做什么、为什么做见 `product.md`。实现时颜色、字号、间距一律引用本文的变量名，不写死数值。

## 1. 设计哲学

Bill 定的三条，排在所有规则前面：

1. **能用图标，就不用文字。** 按钮、开关、状态先找图标。文字只留给图标说不清的地方，例如字幕内容、文件名、AI 的回复。
2. **能用图形表达清楚的逻辑，就不用文本。** 流向用连线，组成用文件图标，进度用进度条，层级用缩进和引导线，时间用时间线上的位置。不写解释性的段落。
3. **简约。** 每个区域只放完成当前任务必需的东西。拿不准时删掉。

由此得出的具体做法：

- 图标按钮必须有悬停提示和 `aria-label`，提示里写名字和快捷键，例如「切割（B）」。屏幕上不显示文字，但读屏软件和悬停都能看到。
- 说明文字、快捷键提示放进悬停提示，不常驻在界面上。常驻的只有状态和数据。
- 一个状态只用一种方式表达。已经有颜色和图标，就不再加一句话。
- 同一屏里，主色按钮最多一个。
- 空状态只放一个图标和一个动作，不写段落。

另外两条来自产品原则：

- **通用。** 文案、图标、默认名都不带题材含义，见 ADR-0013。
- **一个按钮一个动词。** 改变工程或产生文件的控件，都要能对应到一个 MCP 动词，见 `product.md` 第 6 节。

## 2. 颜色

深色界面，和剪辑软件一致，看画面时不刺眼。颜色有固定含义，不拿来装饰。

### 2.1 底色与文字

| 变量 | 值 | 用在 |
|---|---|---|
| `bg` | `#111214` | 窗口底色、输入框底色 |
| `bg-viewer` | `#0E0F11` | 预览区 |
| `bg-timeline` | `#141518` | 时间线 |
| `panel` | `#18191C` | 菜单栏、功能区、参数区、工具栏 |
| `panel-2` | `#1F2125` | 面板里的卡片、选中行 |
| `raised` | `#24262A` | 浮起的元素：用户消息、选中的选项 |
| `raised-2` | `#2C2F34` | 按下的图标按钮、标签 |
| `line` | `#2B2E33` | 分隔线、默认描边 |
| `line-strong` | `#3A3D43` | 次要按钮描边、刻度 |
| `text` | `#ECEAE6` | 主要文字 |
| `text-2` | `#C9CCD1` | 正文、列表内容 |
| `text-3` | `#A6AAB1` | 次要文字、未选中的图标 |
| `text-4` | `#8B9099` | 标签名、时码、提示 |
| `text-off` | `#6C717A` | **只用于禁用状态和装饰**，不用于需要读的文字 |

对比度（WCAG）：`text-4` 在 `raised` 上是 4.7，在其他底色上是 5.5 到 6.0，都达到 4.5。`text-off` 只有 3.1 到 3.9，所以不能用来写提示；草稿 3 里用它写的提示要改成 `text-4`，或者挪进悬停提示。

### 2.2 语义色

| 变量 | 值 | 含义 | 规则 |
|---|---|---|---|
| `attention` | `#F2B04A`，底 `#33280F` | **需要你看**：待定的决定、标记、待查的字幕 | 只用在需要人处理的地方。处理完立即变回中性色 |
| `approved` | `#4FC3A1`，字 `#7FDCC0`，底 `#143027` | **已通过**：批准、已在实机打开过、已定 | 只表示「人确认过」，不表示「AI 做完了」 |
| `primary` | `#ECEAE6` 底、`#111214` 字 | 当前最主要的动作 | 一屏最多一个 |
| `info` | `#9CC2FF`，底 `#1C2A3E` | 引用：`@素材`、素材模式标签 | 不用于状态 |

状态不能只靠颜色区分，还要配图标或形状：待定是实心点，已定是对勾，排队中是空心点。

### 2.3 轨道与文件类型

| 变量 | 值 | 用在 |
|---|---|---|
| `track-video` | `#33507A`，描边 `#45679A`，字 `#DCE6F5` | 视频片段 |
| `track-audio` | `#22564A`，描边 `#2F6E5F` | 声音片段 |
| `track-subtitle` | `#33363C`，字 `#C9CCD1` | 字幕条 |
| `file-fcpxml` | `#B49BFF` | 文件图标色带 |
| `file-otio` | `#7FB8FF` | 同上 |
| `file-xml` | `#A3A3FF` | 同上 |
| `file-srt` | `#C9CCD1` | 同上 |
| `file-mp4` | `#F08C7A` | 同上 |
| `file-wav` | `#8FD3E8` | 同上 |

同一种格式在任何地方都用同一个颜色。

## 3. 文字

| 变量 | 值 | 用在 |
|---|---|---|
| `font-ui` | Noto Sans SC，回退 `system-ui` | 全部界面文字 |
| `font-mono` | JetBrains Mono | 时码、帧数、文件扩展名、快捷键 |
| `size-xs` | 11 px | 片段名、角标、文件名 |
| `size-sm` | 12 px | 标签名、时码、次要信息 |
| `size-md` | 13 px | 正文（默认） |
| `size-lg` | 14 px | 应用名、卡片标题 |
| `size-xl` | 16 px | 一级标题、面板标题 |

字重只用 400、500、700。行高：正文 1.6，长段落 1.7。数字和时码一律等宽字体，保证滚动时不跳。

## 4. 尺寸、间距、圆角

- **间距**按 2 的倍数：2、4、6、8、10、12、14、16、20、24。面板内边距 12 到 16。
- **圆角**：`r-sm` 4（片段、标签、按键）；`r-md` 6（按钮、输入框）；`r-lg` 8（卡片）；`r-xl` 10（大卡片、对话气泡、输入框外框）；`r-pill` 999（状态胶囊）。
- **点击区域**：普通按钮高 32，图标按钮 28×28，紧凑处（列表行内）24×24，不再更小。
- **描边**：1 px；选中或重点用 1 px 的 `text` 色描边，时间线选中片段用 2 px 内描边。

## 5. 布局

| 区域 | 尺寸 | 规则 |
|---|---|---|
| 菜单栏 | 高 41 | 左：应用名、工程、版本。右：AI 草稿状态、导出 |
| 功能区 | 宽 315，最小 280 | 顶部四个标签：AI、素材、章节、字幕 |
| 预览 | 占满剩余宽度，最小 480 | 画面 16:9 居中，下面是时码和播放控制 |
| 参数区 | 宽 417，最小 320 | 跟随功能区的标签切换内容 |
| 工具栏 | 高 35 | 左：编辑工具。右：统计、吸附、缩放 |
| 时间线 | 高 278，可拖动调整 | 轨道名列宽 72 |

窗口变窄时，先压缩预览；预览到最小宽度后，参数区可以收起成抽屉。

## 6. 图标

- 线性图标，16×16 网格，描边 1.5，圆头圆角，颜色跟随文字（`currentColor`）。按钮里显示 14 px，大方块按钮里显示 24 px。
- 同一个含义全局只用一个图标。对照表随实现补充，第一批：

| 含义 | 图标 |
|---|---|
| 导出 | 向上箭头加托盘 |
| 选择 / 切割 / 加标记 | 箭头 / 斜线刀 / 旗子 |
| 撤销 / 重做 | 回转箭头 |
| 吸附 | 磁铁 |
| 搜索 / 查找替换 | 放大镜 / 双向箭头 |
| 网格视图 / 列表视图 | 四格 / 横线 |
| 新对话 / 历史对话 | 带笔的方框 / 列表 |
| 添加 / 删除 | 加号 / 垃圾桶 |
| 进入（整张卡片可点） | 右尖括号 `›`，在卡片右侧上下居中 |
| 智能体 | 星芒 |

- 软件图标（Final Cut Pro、Resolve、Premiere）正式版用真图标，草稿里的字母色块只是占位。

## 7. 组件与状态

每个组件都要画出这些状态：默认、悬停、按下、选中、禁用、键盘焦点。焦点统一用 2 px `text` 色外框，偏移 2 px。

### 7.1 按钮

| 种类 | 外观 | 用在 |
|---|---|---|
| 主按钮 | `primary` 底 | 每屏最多一个 |
| 次按钮 | 透明底，`line-strong` 描边 | 其他文字按钮 |
| 图标按钮 | 无底；按下时 `raised-2` 底、`text` 色 | 工具栏、行内操作 |
| 通过按钮 | `approved` 底、深色字 | 只用于「批准」 |
| 卡片按钮 | 整张卡片可点，右侧一个 `›` | 导出去处、视图切换 |

悬停：底色提亮一级。禁用：`text-off` 色，不响应，悬停提示说明为什么不能用（例如「下个版本」）。

### 7.2 标签页、分段切换

- 标签页：文字或图标，选中项下面 2 px `text` 色线。
- 分段切换（网格/列表等）：底色 `bg` 的小槽，选中项 `raised-2` 底。
- 多个视图平级时，用方块按钮横排：图标在上，文字在下（章节视图）。

### 7.3 输入

输入框高 36，`bg` 底，`line` 描边；聚焦时描边变 `text` 色。下拉框同输入框。勾选框和单选按钮用系统控件，强调色 `text`。能用开关的不用勾选框，能用图标开关的不用开关。

### 7.4 状态标记

- **胶囊**：AI 草稿状态（`attention`）、已批准（`approved`）。
- **角标**：「下个版本」等，放在元素右上角，`raised-2` 底、`size-xs`。
- **进度条**：多段短条，每段一件事，颜色即状态（「决定」顶部）。

### 7.5 对话（AI 面板）

| 元素 | 规则 |
|---|---|
| 用户消息 | `raised` 底气泡，引用的素材显示为 `info` 色小标签 |
| 自动发出的消息 | 和用户消息一样，前面多一个 `attention` 色「决定」标签 |
| 步骤行 | 圆点加一行字加 `›`，可折叠。进行中：`attention` 色圆点带光圈；完成：`approved` 色圆点 |
| AI 回复 | 无底，直接排版；支持列表、粗体、代码 |
| 逐字输出 | 末尾一个文字色竖条光标；输出时发送按钮变成停止按钮 |
| 草稿卡片 | 描边卡片：标题、一行数字、一个「批准」按钮 |
| 回复下的操作 | 复制、有用、没用，三个图标按钮 |

状态：本机没装 Agent、没登录、命令行出错时，对话区只显示一个图标、一句话和一个动作（例如「安装说明」）。

### 7.6 决定卡片

| 状态 | 外观 |
|---|---|
| 排队中 | `line` 描边，只显示问题 |
| 待定（当前） | `attention` 描边，展开选项：编号键、选项名、一句说明，推荐项带「推荐」角标；最后一行是「其他想法」输入框；底部「跳过」「发给 AI」 |
| 已定 | 收起，变淡，显示对勾和选中的答案 |

一次只展开一张。顶部进度条每段对应一张卡片。

### 7.7 素材

- 网格卡片：缩略图（16:7），左上角状态标签（已用 / 未用），右上角时长；选中时变成胶片条，并显示入点到出点的 `attention` 色框。
- 列表行：图标、名称、时长、规格。
- 缩放（`⌘ +` / `⌘ −`）改变缩略图大小，不改变信息量。

### 7.8 时间线

- 轨道名列：「视频 A」「声音 A」「字幕 A」，最上面是「+」加轨道。轨道名不带题材含义，空轨道只显示比底色略亮的一条。
- 片段：选中时 2 px `text` 色内描边；不在当前任务焦点时降到 45% 不透明度（例如校字幕时的画面和声音）。
- 标记：`attention` 色下三角，选中时放大。
- 播放头：2 px `text` 色竖线。
- 字幕条：选中时反白（`text` 底、深色字）。

### 7.9 字幕列表

每行：序号、文字、入点时码，右侧行内操作（加一条、删除）。悬停时才显示行内操作。选中行展开为编辑态：文字框、入点出点、拆分、合并。

### 7.10 导出节点图

- 左：成片预览节点；画面上左右移动鼠标即快速预览，显示播放头和时码。
- 连线：预览节点出一根线接到竖向总线，再分到每张卡片的正中。悬停哪张卡片，哪根线亮。
- 去处卡片：软件图标、名字、状态角标，下面是输出文件图标；右侧 `›`。高度贴合内容。
- 文件图标：折角文档，底部色带写扩展名（`file-*` 色），下面是文件名。可选的输出（直接导出）点击切换：选中时实线框加对勾，未选时虚线框、半透明。

## 8. 交互

### 8.1 快捷键

| 键 | 作用 |
|---|---|
| `空格`、`J` `K` `L` | 播放、倒放、暂停、快进 |
| `I` / `O` | 设入点 / 出点 |
| `Q` | 把选中范围加到时间线 |
| `A` / `B` / `M` | 选择工具 / 切割工具 / 加标记 |
| `⌘ Z` / `⌘ ⇧ Z` | 撤销 / 重做 |
| `⌘ +` / `⌘ −` | 放大 / 缩小（素材缩略图或时间线，取决于焦点） |
| `↑` `↓`、`↵` | 字幕列表上一条、下一条、编辑 |
| `1`–`4`、`↵` | 在当前决定里选择、发给 AI |
| `⌘ F` | 搜索当前面板 |

快捷键写在悬停提示里，界面上不常驻。

### 8.2 通用行为

- 点章节标题、字幕行、标记、决定里的时间点：播放头和预览跳到那里。
- 拖动素材到时间线：显示落点竖线和吸附位置。
- 悬停可点的卡片：描边变亮，`›` 变亮。
- 长任务（识别、导出）：在菜单栏状态位置显示进度，不弹窗，不阻止继续操作。
- 动画只用于状态变化，时长 120 到 200 ms；系统开启「减少动态效果」时关闭。

## 9. 文案

- 用大白话，短句。能用图标的不写字（第 1 节）。
- 动作用动词：「导出」「发给 AI」「跳过」。
- 不带题材：用「素材」「视频 B」，不用「空镜」「采访」。
- 数字用阿拉伯数字，数字和单位之间加空格：「16 条」「0:55」。
- 时码写全：`00:00:09:14`；短时长可以写 `0:55`。

## 10. 无障碍

- 文字对比度不低于 4.5，大字和图标不低于 3。
- 状态不只靠颜色，见 2.2 节。
- 所有图标按钮都有 `aria-label`；切换类按钮有 `aria-pressed`；标签页用 `tablist`；对话框用 `role="dialog"` 并锁定焦点。
- 每个操作都能只用键盘完成。

## 11. 草稿 3 要按本文修改的地方

以下 6 处已在设计稿第 69 版（草稿 4）改完。

1. 常驻的说明文字和快捷键提示挪进悬停提示：素材面板底部的快捷键条、预览右下角的快捷键、章节面板「点标题跳到那里」、导出预览下的说明。
2. 用 `text-off` 写的提示改成 `text-4`，或者删掉。
3. 工具栏统计（「12 个片段 · 11 个标记 · 16 条字幕」）改成图标加数字。
4. 字幕识别设置里「去除水词」的长说明删掉，留在悬停提示里。
5. 导出卡片上的注意事项改成一个 `attention` 色图标，悬停看详情。
6. 决定卡片的选项说明压到一行以内。
